# 💎 Ethiora VIP All-in-One Terminal (`@Ethiora_Aibot`)

An AI-powered DeFi, Multi-Timeframe Chart Analysis, and P2P Stablecoin Terminal built for Telegram, submitted for the **NEAR Protocol Global Online Hackathon**.

## 🚀 Key Features
- **Multilingual AI Crypto & Web3 Assistant**: Answers blockchain, DeFi, and market queries in both Amharic and English with multi-engine fallback resilience.
- **AI Multi-Timeframe Chart Analysis**: Upload 1D, 4H, and 15M candlestick chart screenshots for structured institutional technical breakdowns, liquidity zones, and trade setups.
- **P2P USDT Marketplace**: Create and manage peer-to-peer buy/sell listings with custom rates and local payment support.
- **Live Market Data & PnL Calculator**: Real-time crypto, gold, and forex tickers powered by Binance & CoinGecko APIs alongside an instant ROI/PnL calculator.
- **Built-in Referral System**: Automated user onboarding and reward tracking.

## 🛠 Tech Stack & NEAR Protocol Integration
- **Core Stack**: Python (`pyTelegramBotAPI`), Google Gemini Vision & Multi-LLM Engine, Binance Public API & CoinGecko API.
- **NEAR Protocol Fit**: Designed to leverage **NEAR Intents** and chain abstraction for instant cross-chain swaps, fast account onboarding, and on-chain P2P stablecoin settlement directly inside Telegram.
